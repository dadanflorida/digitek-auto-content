# Digitek Auto Content Engine

Dashboard awal untuk sistem riset pasar, SEO, generator artikel, dan publikasi Blogger Digitek Store.

## Menjalankan lokal
1. Install Node.js.
2. Jalankan `npm install`.
3. Jalankan `npm run dev`.

## Deploy ke Vercel
Import repository GitHub ini ke Vercel. Framework akan terdeteksi sebagai Vite.

## Status
Versi 1: dashboard prototype. Belum terhubung ke Gemini API, sumber riset keyword, Blogger API, atau Google Search Console.

## Catatan Migrasi Express

Pengujian migrasi backend Express dilakukan pada branch express-migration-test.
